# App Store Asset Requirements

**Status:** Draft. No native asset catalog exists in this repository; there is no native iOS target or Xcode project. No binary assets are committed as final.

## 1. Owner / design deliverables

- 1024 x 1024 App Store icon (approved source file; no alpha).
- Native asset catalog (Assets.xcassets) with all required sizes/scales generated from the single approved source.
- Launch screen for supported device classes.
- Screenshot matrix for the iPhone and iPad device classes App Store Connect requires **at submission time** — requirements change, so verify at submission time.
- Localized screenshot copy plan: Arabic and English.

## 2. Screenshot storyboard (based on actual Vibe features)

1. Onboarding
2. Discovery / rooms
3. Cinema / Games / Flash / Echo
4. Private chat
5. Camera / gallery / voice note
6. Profile
7. Report / block safety
8. Settings — privacy, data export, delete account

## 3. Media rules

- Never use real PII in screenshots or previews.
- Use dedicated review/demo accounts with non-personal data.
- App preview video is optional.
- Confirm brand and trademark rights before publishing any asset.
- No fake, placeholder, or fabricated binary assets.
