# معاينة محلية (Preview) — بدون لمس الموقع المنشور

الموقع المنشور https://vibe-social-nights.bb0949.chatgpt.site يعمل كـ Worker واحد
مع أصول مدمجة، وقاعدة D1 للسينما، وحسابات Supabase. لا توجد في المستودع أي طريقة
معاينة جاهزة (لا dev server، ولا wrangler، ولا نشر معاينة)، ولذلك يضيف هذا الفرع
أداة معاينة محلية صغيرة تعمل بلا اعتماديات إضافية.

## التشغيل

```sh
npm ci
npm run preview
```

`npm run preview` يبني `dist/server/index.js` ثم يقدّمه على `http://127.0.0.1:8787/`.
الأمر لا ينشر شيئًا ولا يعرف مشروع الاستضافة (`appgprj_…`) ولا يعدّله.

متغيرات اختيارية:

- `PREVIEW_PORT=3000` لتغيير المنفذ.
- `PREVIEW_HOST=0.0.0.0` عند التشغيل داخل Codespaces أو حاوية مع تمرير المنفذ.
- `PREVIEW_LIVE_BACKEND=1` لتوجيه `/api/cloud/*` إلى مشروع Supabase الحقيقي (انظر التحذير أدناه).

## ما يعمل فعلًا في المعاينة

| المسار | في المعاينة |
|---|---|
| الواجهات (`/` و `/cinema.html` والخطوط والصور) | نفس ملفات `public/` المدمجة في Worker الحقيقي |
| رؤوس الأمان وCSP | من نفس كود Worker، باستثناء إزالة `upgrade-insecure-requests` لأن المعاينة على http |
| `/api/cinema` | مسارات حقيقية مع SQLite محلي في الذاكرة من `drizzle/0000_blushing_lake.sql` — لا يلمس D1 الإنتاجي |
| `/api/video-preview` | حقيقي (قراءة فقط من YouTube oEmbed) |
| `/api/support` | معطّل كما هو الافتراضي في الإنتاج حتى تُضبط متغيرات `SUPPORT_*` و`OPENAI_*` |
| `/api/cloud/*` (الحسابات والغرف والرسائل والرفع) | معطّل افتراضيًا ويعيد `503 preview_offline` حتى لا تُنشأ حسابات أو بيانات على قاعدة الإنتاج |

الحساب الحقيقي داخل المعاينة يحتاج `PREVIEW_LIVE_BACKEND=1`، وهذا يستدعي مشروع
Supabase الإنتاجي نفسه: أي تسجيل أو رسالة ستصبح بيانات حقيقية في نفس القاعدة،
وروابط تأكيد البريد تعود حسب Redirect URLs المسموح بها في Supabase (عادةً عنوان
الموقع المنشور). لذلك: استخدم حسابًا تجريبيًا وقيمًا يمكن حذفها، ولا تستخدمه
لتجربة حذف أو تعديل بيانات تهمك.

## حدود المعاينة

- قد لا يثبت كوكي الجلسة في بعض المتصفحات لأن كوكي `__Host-…` يتطلب اتصالاً آمنًا.
  Chrome/Edge يتعاملان مع `localhost` كأصل موثوق، أما Safari/iOS فقد لا يثبت الجلسة.
  المعاينة الافتراضية (offline) لا تعتمد على الكوكي أصلاً.
- لا خادم HTTPS محليًا: هذا سكربت معاينة تطويري فقط وليس بديلاً عن أسعار الأداء أو اختبار الأجهزة.
- المعاينة لا تحاكي D1 الإنتاجي ولا بيانات السينما الموجودة عليه، ولا رؤوس منصة الاستضافة.
- المعاينة لا تعادل نشرًا حقيقيًا ولا تُغني عن اختبار المتصفح/الجهاز المذكور في `docs/` و`appstore/`.

## Codespaces

`.devcontainer/devcontainer.json` يثبت Node 24 ويمرّر المنفذ 8787 ويعمل `npm ci` عند الإنشاء،
ثم يكفي `npm run preview` وفتح المنفذ من تبويب PORTS.
